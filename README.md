```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m jupyterlab graphic_design_01.ipynb
```

将 `.env.example` 复制为 `.env` 并填写 API 密钥；在 notebook 中启用调用。
