# Rendering instructions

## Image rendering instructions

Render the poster described below. Only the strings in Exact visible text are intended
to appear in the artwork. Preserve their wording, punctuation, language, and intentional
line breaks. Markdown blockquote markers are delimiters, not artwork text. Do not print instructions, section labels, or the
communication objective. Follow the composition, typography, visual treatment,
allowed variation, and exclusions. These instructions do not prescribe a default style.

# Communication objective

Create a portrait English poster inviting people under everyday productivity pressure to allow a brief pause.

# Intended audience and viewing context

Students or office workers feeling pressure to stay productive.

A poster encountered briefly in a shared indoor space.

# Exact visible text

> YOU DON’T HAVE TO FILL EVERY MINUTE.

> LEAVE A LITTLE ROOM.

# Visual composition

Main copy in large, highly legible dark charcoal sans-serif type, arranged in a calm grid with a deliberate generous vertical gap between “EVERY” and “MINUTE” so the sentence visibly pauses.

Place the supporting copy beneath the main message with generous surrounding whitespace.

# Typography

Large, highly legible dark charcoal sans-serif type for the main copy.
Smaller supporting copy beneath the main message. Minimal editorial typography,
strong hierarchy, and clear readability from several feet away.

# Visual treatment

Use a warm off-white background and one restrained muted blue-green accent, minimal editorial typography, strong hierarchy, and clear readability from several feet away.

# Allowed variation

Allow subtle variations in typeface, spacing, and accent placement while preserving the sentence, the intentional gap, portrait format, and inviting tone.

# Exclusions

- Clocks.
- Phones.
- Sleeping people.
- Office scenes.
- Busy patterns.
- Alarmist imagery.
- Guilt-inducing language.
- Unsupported factual claims.
- Extra text.
- Illegible typography.
- Ornate decoration.
