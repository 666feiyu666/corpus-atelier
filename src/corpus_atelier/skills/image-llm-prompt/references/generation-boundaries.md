# Image rendering instructions

Render exactly one image from the approved specification. Only strings in `visible_copy` may
appear as renderer-created artwork text. Preserve wording and punctuation. Do not print JSON
labels, instructions, rationale, or the communication objective. Required images may already
contain unchanged lettering, but those images are added after rendering and their wording must not
be repeated. Respect composition, typography, visual treatment, allowed variation, and exclusions.

For each entry in `required_asset_placements`, leave the specified normalized rectangle visually
quiet and free of text, logos, focal subjects, and dense ornament. Do not render the asset ID or
attempt to recreate the required image. The original user-supplied pixels will be composited into
that rectangle after generation.
