# GPT Image 2 compilation guidance

- Describe one resolved image in direct visual language.
- Introduce the main subject and entity relationships before decorative detail.
- Keep identities stable instead of renaming the same entity across sections.
- State counts only when count matters to the design or prevents duplication.
- Express placement, relative scale, depth, attachment, overlap, and visibility concretely.
- Use exact visible copy verbatim and forbid additional pseudo-text when the design requires it.
- Translate visual priority into placement, local contrast, lighting, sharpness, and detail rather
  than repeating abstract claims of importance.
- When a reference image is attached, describe how the new image uses it; do not invite the model
  to copy every visible feature or introduce content solely because it appears in the reference.
- Keep exclusions short and specific to plausible failures of the current design.
