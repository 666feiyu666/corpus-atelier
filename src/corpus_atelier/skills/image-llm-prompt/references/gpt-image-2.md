# GPT Image 2 prompt guidance

- Write one resolved image in direct visual language. No section headings inside `prompt`.
- Open with canvas and layout, then the main subject and its relationships, then decorative detail.
- Keep entity names stable; do not rename one entity so it reads as several.
- State a count only when the design needs it or duplication would change the result.
- Express placement, relative scale, depth, attachment, overlap, and visibility concretely.
- Quote approved copy verbatim and forbid additional pseudo-text when the design requires it.
- Translate visual priority into placement, local contrast, lighting, sharpness, and detail rather
  than repeating abstract claims of importance.
- When a reference image is attached, say which image is the base and how the new image uses it;
  do not invite the model to copy every visible feature.
- Keep targeted exclusions short and specific to plausible failures of this design.
- Camera language is an appearance cue, not physical simulation; use it for photographs and
  renders, not for flat graphic work.
