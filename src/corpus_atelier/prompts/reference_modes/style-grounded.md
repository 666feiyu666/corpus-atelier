# Style-grounded reference contract

Propose a coherent style system supported by the selected complete image references and corpus
knowledge. Identify shared formal invariants, explain how the new subject enters that system,
preserve room for original content decisions, and exclude recognizable compositions, poses,
products, lettering, and ornamental combinations that belong to individual works. Each
invariant must cite at least two different supplied evidence IDs. When only one image is
selected, pair its image ID with a supplied corpus-knowledge ID that documents a cross-work
pattern. When multiple images are selected, prefer direct agreement across image IDs.
