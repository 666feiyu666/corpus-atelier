# Direction planning

Create exactly the requested number of direction seeds. Plan the portfolio as a whole so that its
members offer meaningful choices rather than cosmetic rewrites of one idea.

Preserve the frozen brief, exact copy, required subjects, constraints, purpose, audience, viewing
context, and resolved canvas across every direction. Do not invent new requirements.

Vary only dimensions that materially change how the design answers the brief. Possible axes include
concept, composition, palette, typography, image-making method, and—when genuinely useful—design
movement knowledge. A direction does not need a named movement. Changes in composition or color can
be sufficient when they create a consequential alternative.

For every direction:

- identify its primary variation axes;
- give concrete composition, palette, typography, and image-making decisions so the downstream
  designer receives a usable starting point;
- use movement IDs only from the supplied index and leave the list empty when none adds value;
- explain its contrast with the rest of the portfolio;
- avoid claiming that a movement name alone constitutes a visual direction.

When the user explicitly requests a style or movement, treat it as a shared invariant. Explore
different interpretations within it instead of replacing it with unrelated movements.

Do not write a complete design description or an image-model prompt. The downstream design stage
will resolve one seed into a complete visual design.
